# My-Capstone-Project
### Project Overview – Health360 Healthcare Analysis

**Health360 Healthcare Analysis** is a data analytics capstone project focused on analyzing healthcare data to identify chronic disease patterns and understand the impact of clinical and lifestyle risk factors.

The project analyzes **5,000 patient records** using **Python, SQL, Snowflake, and Tableau**. It explores Diabetes, Heart Disease, and Stroke through interactive dashboards and 8 visualizations, including bar charts, line charts, heatmaps, bubble charts, scatter plots, and pie charts.

The project aims to transform raw healthcare data into meaningful insights that support early risk identification, healthcare analysis, and informed decision-making.
